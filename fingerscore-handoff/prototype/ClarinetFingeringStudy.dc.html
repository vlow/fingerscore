Clarinet fingering charts — same system as the sax

Written pitch, B♭ clarinet. Same column of 3 + 3 rings as Xaphoon and sax. The register key and thumb hole sit at top left, like the Xaphoon thumb hole; A and G♯ keys above the column, pinky keys left and right, side keys to the right.

Key positions
Top left: register key (small), thumb hole below it
Above the column: A key and G♯ key (left index finger)
Column: LH rings 1–2–3, gap, RH rings 1–2–3
Left, middle: left pinky E and F♯/C♯ keys
Right, middle: four side (trill) keys
Right, low: right pinky F and A♭/E♭ keys
Why clarinet looks different: its register key jumps a twelfth, not an octave — B4 is fingered like E3 plus the register key.
Throat tones (G4–B♭4) use almost no fingers and are drawn nearly empty — that is correct, not a missing chart.
