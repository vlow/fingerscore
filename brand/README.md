# fingerscore brand assets (logo concept E: "f-mark")

- `mark.svg` — logo mark for light backgrounds (ink #15171C, closed hole teal #0E6E68). Use from 24 px up.
- `mark-on-dark.svg` — for dark backgrounds (#F3F4F6, mint #5FD3C6).
- `favicon.svg` — simplified, heavier version for 16–48 px; switches colours with `prefers-color-scheme`. Also export `favicon.ico` (16/32/48) and `apple-touch-icon.png` (180) from it / from `app-icon.svg`.
- `app-icon.svg` — 180×180 rounded square (teal) for PWA/apple-touch icons; export PNGs at 192 and 512 for the web manifest.
- `wordmark.svg` — lockup reference; the text uses Atkinson Hyperlegible Bold ("finger" ink, "score" teal). Convert text to outlines before using it as a standalone file.

Clear space: at least the diameter of the open hole on all sides. Minimum size: mark 24 px, favicon variant below that.
The lowercase "f" + hole crossbar should stay clearly visible at every size (distinctiveness vs. other "f" marks).
Trademark: not yet cleared — run the image searches (DPMA, EUIPO, WIPO) / attorney clearance before registering or launching.
